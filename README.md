# System Boot

System Boot is the process of starting a computer or mobile device and loading the Operating System (OS).

## Computer System Boot

SMPS → Power ON → BIOS/UEFI → POST → Bootloader → OS → System Running

### Steps

1. **SMPS** – Supplies power to the computer.
2. **Power ON** – The computer is switched on.
3. **BIOS/UEFI** – Starts and initializes the hardware.
4. **POST** – Checks whether the basic hardware is working properly.
5. **Bootloader** – Locates the Operating System on the storage device.
6. **OS Loading** – The Operating System is loaded into RAM.
7. **OS Running** – The Operating System starts and the computer is ready to use.

## Mobile System Boot

Mobile devices use firmware to start the boot process.

Power ON → Firmware → Bootloader → Operating System → System Running

The firmware starts the hardware and the bootloader loads the Operating System.

## Key Points

- **BIOS/UEFI** → Starts and initializes the computer.
- **POST** → Checks the hardware.
- **Bootloader** → Finds and loads the Operating System.
- **RAM** → Temporarily holds the running OS and programs.
- **Firmware** → Software stored in non-volatile memory that helps start the device.

## Conclusion

System Boot is the process of starting a device, initializing its hardware, loading the Operating System into memory, and making the system ready for use.
